# Ambiente experimental

- `ambiente-<data>.json` — gerado por `npm run env` (S01). Regerar se algo for atualizado.
- `hashes.md` — SHA-256 dos .zip de `data/raw/` (S08).
- `aviso-sti.md` — cópia do e-mail enviado à STI/SINFO antes da coleta.

**Regra:** não atualizar Chrome, Node ou Lighthouse entre a coleta (S08) e a validação (S18).
Se for inevitável, registrar aqui e no diário.
