## Problemas / dúvidas para o orientador
- **Redirecionamentos.** A checagem de DNS vale só para o host digitado. Se a sondagem seguir um redirecionamento para outro domínio, o destino não é checado. O ADR cobre o risco pela proibição de publicar o servidor, mas não cita esse caso.
- **Memória do servidor.** As análises ficam na memória. Depois de reiniciar o servidor, o `GET /api/analises` volta vazio, embora os resultados continuem acessíveis pelo `analise.json` de cada pasta.
- **Código depois da `v1.0`.** O `src/ui/` é código novo e não altera os módulos 0 a 4. A tag prevista é `v1.1-interface`, ao fim da S21.
- **Arquivo de fora da sessão.** O `scripts/_tmp_elegiveis.ts` (não rastreado, criado às 17:57) não é desta sessão. Ficou intocado.
