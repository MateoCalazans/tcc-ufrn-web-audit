## Decisões tomadas
- **Nenhuma exige ADR novo.** Registradas aqui por transparência:
  - Timeout padrão de **15 s** no cliente HTTP, alinhado ao critério de exclusão `timeout` do **ADR 002**.
  - O espaçamento de 2 s do limitador é medido **entre os inícios** de duas requisições consecutivas ao mesmo host; `lastStart` é mantido por host (não zerado ao esvaziar a fila) para que a pausa valha também entre requisições **sequenciais**, não só concorrentes.
  - `isGitDirty()` assume **`true`** quando o git está indisponível (lado conservador para reprodutibilidade).
  - `src/shared/types.ts` é **rascunho** declarado — os tipos serão refinados nas fases seguintes.
